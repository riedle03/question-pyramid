# 질문 피라미드 소개와 설치 안내

학생이 작품을 읽고 질문을 되도록 많이 만들어, 질문 하나를 벽돌 하나로 쌓는 수업용 게임 '질문 피라미드'의 소개와 설치 안내 페이지입니다.

- 페이지: https://riedle03.github.io/question-pyramid/
- 설치는 구글 시트 템플릿의 '사본 만들기'로 합니다. 페이지의 '설치하기' 탭을 따라 해 주세요.
- 이 저장소에는 안내 페이지만 있습니다. 게임 코드는 들어 있지 않습니다.

원작 질문 피라미드, 미림마이스터고 이대형
